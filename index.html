آخر تحديث: 20 أكتوبر 2026. الأداة مخصصة للاستخدام الشخصي لصاحب القناة، وليست خدمة تتيح ربط حسابات الجمهور أو الأطفال. لا توجد نماذج تجمع بيانات زوار هذه الصفحة، ولا نضيف إليها إعلانات أو أدوات تتبع أو تحليلات.

يُطلب من صاحب الحساب تفويض Google بصلاحيتي youtube.upload وyoutube.readonly. تستخدم الأداة بيانات القناة وقائمة فيديوهاتها ومعرّفات الفيديو والعناوين والأوصاف وحالة النشر للتحقق من القناة الصحيحة، ومنع الرفع المتكرر، والتأكد من نجاح الجدولة. ولا تطلب قراءة Gmail أو جهات الاتصال أو ملفات Google Drive.

تحفظ إعدادات الربط محليًا خارج ملفات المشروع. وعند موافقة صاحب الحساب، يُحفظ رمز تفويض الرفع في GitHub Actions Secrets داخل مشروعه الخاص لتمكين التشغيل السحابي. تحتفظ سجلات المشروع بمعرّفات الفيديوهات وعناوينها ومواعيدها، وتُحفظ فيديوهات المعاينة وتقارير الجودة في نتائج التشغيل لفترة يومين. قد تحفظ خدمات Google وGitHub سجلاتها التشغيلية وفق سياساتها.

تستخدم الأداة خدمات Google وYouTube للربط والرفع، وخدمات GitHub لتشغيل البرنامج وحفظ النتائج. ويُرسل نص التعليق التعليمي إلى محرك الصوت عبر مكتبة edge-tts؛ لا تتضمن هذه النصوص بيانات الحساب أو رموز التفويض. لا تُباع بيانات حساب Google ولا تُستخدم للإعلانات أو تدريب نماذج الذكاء الاصطناعي.

يقتصر استخدام بيانات Google على الوظائف المبينة هنا، ويخضع لسياسة بيانات مستخدمي خدمات Google API بما فيها متطلبات الاستخدام المحدود. يمكن لصاحب الحساب إيقاف التشغيل، وحذف سر GitHub وملفات التفويض المحلية وسجلات المشروع، وإلغاء الوصول من إعدادات اتصالات حساب Google. حذف التفويض لا يحذف الفيديوهات المرفوعة تلقائيًا؛ يديرها صاحب القناة من YouTube Studio.

هذه الأداة لا تجمع بيانات المشاهدين أو الأطفال. إعداد «مخصص للأطفال» يطبّق على فيديوهات القناة. يمكن لصاحب الحساب مراجعة ممارسات الأداة وتعديلها من مشروعه الخاص قبل الموافقة على أي تغيير في نطاق الصلاحيات أو استخدام البيانات.

شروط استخدام الأداة

الأداة برنامج شخصي لإدارة قناة يملكها صاحب الحساب. يراجع صاحب القناة محتواها وصلاحياتها ويظل مسؤولًا عن حقوق المواد ودقتها وملاءمتها للأطفال، وعن الالتزام بشروط YouTube وGoogle وGitHub والخدمات المستخدمة.

قد يتعطل توليد الصوت أو التشغيل أو الرفع بسبب عطل أو انتهاء التفويض أو حدود الحصة المجانية أو قيود مزود الخدمة. لا تقدم الأداة ضمانًا لمواعيد التشغيل أو النشر أو عدد المشاهدات أو الأرباح. الإعداد المقصود يقتصر على الحصص المجانية، ولا يفعّل الاشتراكات أو الفوترة تلقائيًا.

هذه الصفحة تخص أداة التشغيل. لا تنشئ حسابات للمشاهدين ولا تمنح زوارها وصولًا إلى القناة أو المشروع الخاص.
